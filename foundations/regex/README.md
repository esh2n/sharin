# foundations/regex — 正規表現エンジン(NFA / DFA)の最小実装

バックトラッキングではなくオートマトンで動く正規表現エンジンを、決定的な Go で自作する。
Ken Thompson 方式。3 本柱:

1. **パース**(`parser.go`): 正規表現の文字列を AST にする再帰下降パーサ。優先順位は
   選択(`|`)< 連接 < 繰り返し(`* + ?`)。対応構文: リテラル・`.`・グループ `()`・`|`・`* + ?`。
2. **Thompson 構成**(`nfa.go`): AST を ε 遷移付きの NFA にする。各演算子に対応する
   小さな NFA 断片を組み合わせる。
3. **シミュレーションと DFA 化**(`nfa.go` / `dfa.go`): NFA を「状態集合」として並行に進める
   (バックトラッキング無し、入力長に比例)。あるいは部分集合構成で DFA に変換して 1 文字 1 表引き。

## 実行

```sh
go test -race -cover ./foundations/regex/
```

`-race`・`go vet` クリーン、カバレッジ 98.1%。NFA と DFA が同じ判定を返すことを表で検証し、
`(a*)*b` のような ReDoS パターンでも指数爆発しないことを確かめている。教科書の該当章は
`docs/parts/regex.md`。
