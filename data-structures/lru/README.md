# data-structures/lru

## 肝

- LRU は「map + 自作双方向リスト」の組み合わせ。map でノードへ O(1) で飛び、
  リストで「最近使った順」を O(1) で並べ替える
- Get も「値を読む」だけでなく「先頭へ動かす」操作。この移動が LRU の本体
- 追い出した要素は捨てずに呼び出し側へ返す。バッファプールが
  「dirty ページを書き戻してから捨てる」後始末をするための設計

## 簡略化したこと

- スレッド安全ではない(利用側がロックする。bufferpool 参照)
- TTL や重み付きサイズはなし(エントリ数のみ)
- スキャン耐性なし(1回きりの大量アクセスで全部追い出される。実物は midpoint 挿入等で対策)
