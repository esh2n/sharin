# data-structures/bloomfilter

ブルームフィルタ。要素を保存せずビット配列だけで集合の所属を判定する確率的データ構造。

## 肝

- 答えは「たぶん入っている(偽陽性あり)」か「絶対に入っていない(確実)」の2択。
  偽陰性は起きない——入れたものは必ず「あるかも」と答える
- 要素そのものを持たないので圧倒的に省メモリ。その代わり「ある」は嘘のことがある
- 欲しい偽陽性率 p と件数 n から、ビット数 m とハッシュ数 k を計算で逆算できる
  (m = -n·ln p / (ln2)², k = (m/n)·ln2)

## 簡略化したこと

- 削除できない(ビットを消すと他の要素の判定を壊す。実物は counting filter で対応)
- ダブルハッシュ法で k 個のビット位置を作る(独立ハッシュ k 個は用意しない)
- サイズ固定(入れすぎると偽陽性率が悪化する。scalable bloom filter は扱わない)
