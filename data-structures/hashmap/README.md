# data-structures/hashmap

チェイン法のハッシュマップ。

## 肝

- ハッシュ関数でキーを「バケット番号」に変換し、その1バケットだけ見るから平均 O(1)
- 衝突(別キーが同じバケットに落ちる)はバケット内のリストで吸収する(チェイン法)
- 負荷率(件数/バケット数)が上限を超えたらバケットを倍増して配り直す(rehash)。
  これを怠ると衝突が増えて O(1) が O(n) に劣化する。rehash は O(n) の「たまに重い」処理

## 簡略化したこと

- チェイン法のみ(オープンアドレス法は扱わない)
- ハッシュ関数は外から注入(HashString / HashInt を用意)。実物は型ごとに最適化
- 縮小はしない(要素が減ってもバケットは減らさない)
- 並行安全でない(実物の sync.Map やロック分割は扱わない)
