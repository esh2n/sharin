# data-structures/skiplist

スキップリスト。確率で階層を作った連結リストで、平衡木と同じ O(log n) を回転なしで得る。

## 肝

- 最下段は全要素を繋ぐソート済み連結リスト。その上に「飛ばし読み用」の疎な段を積む
- 各ノードの高さをコイン投げで決めるだけ。表が続く限り高くする(高さ1が1/2, 2が1/4…)
- 検索は上の疎な段で大きく飛ばし、下の段で詰める。回転(AVL/赤黒木)のような複雑な
  再平衡がいらないのが利点。Redis の sorted set の中身

## 簡略化したこと

- 乱数シード固定(再現性のため)。実物はランダムシード
- 値は int 固定、スコア付き(ZSET)ではない
- 段の上限は固定16。span(順位クエリ用の距離)は持たない
