# data-structures/bst

## 肝

- ルールは1つ:「左の子孫は自分より小さく、右の子孫は大きい」。これだけで
  検索も挿入も「比較して片側へ降りる」になり、1回の比較で候補が半分になる
- 速さの正体は高さ。バランスが取れていれば高さ ≈ log2(n)
- 木の形は「挿入された順序」だけで決まる。昇順に入れると一本鎖(高さ n-1)に崩壊する。
  これが平衡木(AVL / 赤黒木 / B-Tree)が存在する理由
