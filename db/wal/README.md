# db/wal

Write-Ahead Log の最小実装。db 編の第2段。題材は送金(2ページの原子的な書き換え)。

## 肝

- 原則は1つ:「ページを書き換える前に、やることをログに書け」(write-ahead)
- commit レコード + fsync が完了した瞬間が「やる」と確定する境界線。
  リカバリは commit 済みなら redo、なければ捨てる — 中途半端だけが絶対に起きない
- redo が冪等(Set は「+100」でなく「1100にする」)だから、
  どこで死んでも「全部やり直す」で必ず正しい状態になる

## 簡略化したこと

- redo のみ(undo なし)。適用は commit 後に限るので巻き戻しが不要な設計
- 同時実行なし(単一 mutex)。トランザクションの分離は扱わない
- レコードに CRC なし。ページ内部の部分書き込み(torn page)も扱わない
- checkpoint は毎回実行(実物は WAL を溜めて定期的に行う)
