# db/bufferpool

バッファプール(ページキャッシュ)。db 編の第3段。

## 肝

- ディスクのページとメモリの間に立つ唯一の窓口。読み書きはすべてここを通る
- 書き込みはキャッシュ上のページに dirty の印を付けるだけ。ディスクへの書き戻しは
  追い出されるときか FlushAll まで遅延する(速さの源泉)
- 追い出し(LRU)で dirty ページに当たったら、捨てる前に書き戻す
- ヒット率が実効速度を決める。同じページを触り続ければ99%、毎回違えば0%
  (B-Tree の右端挿入=昇順キーが速い理由の最終ピース)

## 簡略化したこと

- pin/unpin なし(使用中ページの追い出し防止。並行アクセス前提の実物には必須)
- WAL との統合なし(dirty ページを書く前に WAL を書く LSN 比較のルールは wal 編参照)
- 追い出しは素の LRU(実物は clock や midpoint 付き LRU 変種)
