# crypto/jwt

JWT(JSON Web Token)を HMAC-SHA256 署名で自作。auth 編の中核。

## 肝

- JWT は「サーバが署名した通行証」。中身(誰か・期限)は誰でも読めるが、
  署名は秘密鍵を持つサーバしか作れない。だから改竄できない
- 形式は "header.payload.signature" の3パート(base64url + ドット区切り)
- サーバはトークンを覚えなくてよい(ステートレス)。署名を検証するだけで
  「自分が発行した、改竄されていない」が分かる

## 簡略化したこと

- HS256(共通鍵の HMAC)のみ。RS256(公開鍵署名)は crypto 編の RSA を使えば作れる
- クレームは sub と exp だけ(iss/aud/nbf など標準クレームは省略)
- alg=none 攻撃は「alg を読まず HS256 固定」で防ぐ(実物も検証側で alg を固定すべき)
- リフレッシュトークン・失効リストは扱わない(ステートレスゆえの弱点は章で説明)
