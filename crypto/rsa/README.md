# crypto/rsa

RSA 公開鍵暗号を小さな素数で自作。暗号と認証編の土台。

## 肝

- 公開鍵暗号の魔法は「暗号化の鍵(公開)と復号の鍵(秘密)が別」なこと。誰でも暗号化でき、
  復号できるのは秘密鍵の持ち主だけ。これで「鍵をどう安全に配るか」問題が解ける
- 安全性は「大きな数の素因数分解は難しい」に依る。n=p·q は公開するが、
  p, q(と φ)を知らないと秘密鍵 d は求まらない
- 暗号化(公開鍵で上げる → 秘密鍵で戻す)と署名(秘密鍵で上げる → 公開鍵で戻す)は
  鍵の使う向きが逆。同じ数式の裏表

## 簡略化したこと

- 極小の素数(教科書例 p=61, q=53)。実物は数百桁。**安全ではない、教材専用**
- パディング(OAEP/PSS)なし。実物はこれがないと破られる
- メッセージは n 未満の整数1つ。ブロック分割やハッシュへの署名は章で説明
- 素数生成・素数判定は素朴(実物は Miller-Rabin で確率的判定)
