# patch — マルチモーダル入口(パッチ化)

画像をトークン列に変える入口(ViT 方式のパッチ化)を最小構成で実装する。テキストの BPE に対応する画像側のトークナイザ。

## 肝

- **パッチ化**: 画像を size×size の格子に切り、各パッチを行優先で平坦化。224×224 を 16×16 で切ると 196 パッチ(テストで固定)
- **線形射影 + 位置埋め込み**: 平坦化パッチを dModel 次元に射影してトークン化。位置埋め込みで、同じ内容のパッチも位置が違えば別トークンになる
- **トークン数 = 計算コスト**: パッチが細かいほどトークンが増える(8×8 は 16×16 の 4 倍)。動画は フレーム数 × 画像トークンで膨大に

## 使い方

```go
patches, _ := patch.Patchify(image, 16)     // 画像 → パッチ列
proj := patch.NewProjector(16*16, 768, seed) // patchDim → dModel
tokens := proj.ToTokens(patches)             // トークン列(Transformer へ)
patch.NumPatches(224, 16)                     // = 196、トークン数見積もり
```

## 簡略化したこと

- **1 チャネル**: グレースケール相当。実物は RGB 3 チャネル(patchDim = 16×16×3)
- **学習可能位置埋め込みでない**: 決定的な固定値。実物は学習する
- **[CLS] トークンなし**: ViT の分類用トークンは扱わない
- **音声・動画は概念のみ**: 章でトークン数の見積もりとして触れる
