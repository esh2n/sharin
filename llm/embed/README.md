# embed — 埋め込みとベクトル検索

文の埋め込み(意味のベクトル化)とベクトル検索を最小構成で実装する。RAG や意味検索の土台。

## 肝

- **平均プーリング**: トークン埋め込みを平均して 1 本の文ベクトルにする。最も素朴なプーリング
- **コサイン類似度**: `a·b / (|a||b|)`。向きだけを見て長さに依存しない。同じ向き 1・直交 0・逆向き -1。ゼロベクトルは 0(NaN を出さない)
- **正規化 = 内積で類似**: 正規化済みベクトルの内積はコサイン類似度そのもの。事前正規化で検索を速く
- **総当たり検索は件数に線形**: 全ベクトルと比較する。`SearchCounted` の ops が件数に一致することを固定。billion 件で破綻し ANN(近似最近傍)が要る理由

## 使い方

```go
v := embed.MeanPool(tokenEmbeddings)   // 文ベクトル
embed.Cosine(a, b)                      // 類似度 [-1,1]
s := embed.NewStore()
s.Add("cat", catVec)
hits := s.Search(queryVec, 5)           // 上位5件、スコア降順
```

## 簡略化したこと

- **埋め込みモデルなし**: ベクトルは外から与える前提。実物は BERT 系や専用エンコーダで生成
- **ANN なし**: 総当たりのみ。HNSW・IVF などの近似最近傍は章で解説。「なぜ要るか」を件数で示す
- **プーリングは平均のみ**: attention 重み付き平均や [CLS] トークンは扱わない
- **距離指標はコサインのみ**: ユークリッド・内積は言及のみ
