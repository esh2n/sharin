# bpe — BPE トークナイザ

LLM の入口でテキストをトークン ID 列に変える BPE(byte-pair encoding)を最小構成で実装する。

## 肝

- **併合の学習**: コーパスで最も頻出する隣接ペアを 1 トークンに併合する、を指定回数繰り返すだけの貪欲アルゴリズム。頻出語ほど少ないトークンで表せるようになる
- **チャンク分割**: 空白を次の語の先頭に付けて割る(GPT-2 流)。チャンクの連結が必ず元の文字列に戻るので、encode → decode の忠実性が構造的に保たれる
- **決定性**: 同数ペアは辞書順でタイブレーク。同じコーパスからは必ず同じ語彙ができる

## 使い方

```go
tok := bpe.Train(corpus, 100)     // 100 回併合を学習
ids := tok.Encode("low lower")    // → トークンID列
text := tok.Decode(ids)           // → "low lower"
toks := tok.Tokens("low lower")   // → ["low", " low", "e", "r"] など切り方の確認
```

## 簡略化したこと

- **基底が rune**: 実物(GPT-2 以降)はバイト基底で未知文字が原理的に生じない。ここでは rune 基底 + `<unk>` で単純化
- **事前分割が空白のみ**: 実物は正規表現で句読点・数字なども切り分けてから BPE を適用する
- **正規化なし**: Unicode 正規化(NFC 等)や大文字小文字の扱いは持たない
