# ssm — 状態空間モデル(Mamba の核)

attention の O(n²) に対し、線形時間の状態空間モデルを最小構成で実装する。

## 肝

- **線形漸化式**: `h_t = A·h_{t-1} + B·x_t`、`y_t = C·h_t`。1 個の状態を系列に沿って更新する。1 ステップ定数・全体線形(ScanCounted の ops が系列長に一致することを固定)
- **減衰と保持**: |A|<1 なら過去の影響が指数的に薄れ、A=1 なら累積和になる。テストでインパルス応答の減衰と累積を固定
- **選択的 SSM(Mamba の核)**: 入力ごとにゲート(取り込み量)が変わる。ゲート 0 のトークンは状態を素通り、1 のトークンは強く取り込む。「関係ある情報だけ残す」を系列上で選べる
- **対照**: `AttentionOps(n) = n²` と `ScanCounted` の n を並べて、線形と二次の差を示す

## 使い方

```go
m := &ssm.SSM{A: 0.9, B: 0.1, C: 1.0}
y := m.Scan(x)                        // 線形時間スキャン
_, ops := m.ScanCounted(x)            // ops == len(x)
ssm.AttentionOps(len(x))              // 対照: n²

s := ssm.NewSelective(0.9)
y2 := s.ScanSelective(x, gate)        // gate[t]∈[0,1] で取り込み量を制御
```

## 簡略化したこと

- **1 次元・スカラー**: 実物は状態が多次元ベクトル、A/B/C は行列。ここはスカラーで漸化式の本質だけ
- **並列スキャンなし**: 逐次ループで実装。線形性から並列プレフィックススキャンで高速化できる(Mamba の実装点)が、計算量の議論には逐次で十分
- **HiPPO 初期化なし**: 実物の A は長距離記憶に有利な特別な初期化(HiPPO)を使う。ここは減衰の直観に絞った
- **拡散 LM は扱わない**: 章の解説のみ
